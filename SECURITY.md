# Security Policy

## Supported versions

Only the latest `main` branch receives security updates.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

- Preferred: [GitHub Security Advisories](../../security/advisories/new)
- Alternative: email `your-email@example.com`

You will receive a response within 48 hours. Please include:

- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested fix (if any)
